Plate Clerk is an offline guide and tracker for the 55 official PlayStation 5 trophies of Grand Theft Auto VI. Each trophy has a cited step-by-step guide, with a platinum roadmap, missable warnings, and a spoiler shield, and the app works with the network off.

## Run it

```sh
python3 -m http.server 8137 -d app
```

then open http://127.0.0.1:8137
