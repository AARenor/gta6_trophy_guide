Quire is an offline PlayStation 5 trophy ledger for Grand Theft Auto VI. It tracks all 55 official trophies, keeps a cited guide beside each one, and lays out a platinum roadmap with missable windows flagged from the source notes.

## Run it

```sh
python3 -m http.server 8137 -d app
# open http://127.0.0.1:8137
```
