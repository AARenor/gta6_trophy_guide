Bridge Log is an offline PlayStation 5 trophy tracker for GTA VI that lists all 55 trophies with a cited guide, a platinum roadmap, missable flags, and a spoiler shield. Filters, search, and browser-local export and import keep progress on this machine with no network load.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
